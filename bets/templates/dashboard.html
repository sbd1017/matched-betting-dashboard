How these figures are worked out
  • Realised profit {{ fmt(s.profit_lifetime, signed=True) }} = every settled result, reward and adjustment, plus the stakes of settled bets. Deposits and withdrawals never count.
  • Still to come {{ fmt(come.total, signed=True) }} = {{ fmt(come.locked, signed=True) }} (the worse outcome of each open position) + {{ fmt(come.free_bets) }} (free bets held × {{ come.retention.snr.pct }}% retention{{ ', from your ' ~ come.retention.snr.count ~ ' settled free bets' if come.retention.snr.own else ', a typical figure until you have settled 3' }}){% if come.rewards %} + {{ fmt(come.rewards) }} (rewards you have qualified for){% endif %}.
  • Available to bet {{ fmt(s.available) }} = bookmakers {{ fmt(s.bookmaker_balance) }} + exchanges {{ fmt(s.exchange_balance) }} − lay liability held {{ fmt(s.lay_liability) }}.
  • Check: betting balances {{ fmt(s.betting_balance) }} = your capital {{ fmt(s.own_capital) }} + temporary funding out {{ fmt(s.temporary_outstanding) }} + retained profit {{ fmt(s.retained_profit, signed=True) }} − stakes in play {{ fmt(s.unsettled_stakes) }}{% if s.consistent %} ✓{% endif %}.
